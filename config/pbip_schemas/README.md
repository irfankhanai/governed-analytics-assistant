# Microsoft report schemas

These ten unmodified public JSON schemas were retrieved on 2026-11-07 from
https://developer.microsoft.com/json-schemas/fabric/ . Directory paths preserve the URL suffix.
Upstream repository: https://github.com/microsoft/json-schemas . See LICENSE for Microsoft's MIT license.

They validate PBIP, PBIR, the semantic-model descriptor, and related visual/query structures offline.
They do not validate execution of M queries, the complete TMSL model, or Power BI Desktop rendering.
No network calls are made by the application or tests to resolve schemas.
